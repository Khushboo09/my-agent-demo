# Student REST Service

A simple Spring Boot microservice that manages student records. It exposes CRUD endpoints, connects to a MySQL database, and is containerised with Docker. Deployment manifests for Kubernetes (deployment, service, HPA, ingress) are provided in the *Yaml Files* directory.

The project demonstrates basic REST API design, data persistence, and cloud‑native deployment.
# Student REST Service

A simple Spring Boot microservice that manages student records. It exposes CRUD endpoints, connects to a MySQL database, and is containerised with Docker. Deployment manifests for Kubernetes (deployment, service, HPA, ingress) are provided in the *Yaml Files* directory.
